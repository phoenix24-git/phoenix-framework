# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming.
- Assume good intent.
- Give and accept constructive feedback.
- Focus on what is best for the community.

Harassment, discrimination and personal attacks are not tolerated in issues, pull requests,
discussions or any other project space.

Report unacceptable behaviour privately to the maintainers through a
[GitHub security advisory](https://github.com/phoenix24-git/phoenix-framework/security/advisories/new)
marked "Code of Conduct". Reports are handled confidentially. Maintainers may remove content or
restrict participation, following the Covenant's enforcement guidelines.
