|---|---|---|
| `icons/` | 1,021 SVG editor icons from Godot Engine 4.7.2 | MIT, © Godot Engine contributors |
| `fonts/` | Inter, JetBrains Mono, Noto Sans, Open Sans, Vazirmatn (OFL-1.1) and Droid Sans (Apache-2.0) | see the `LICENSE.*.txt` files in `fonts/` |

These come from Godot via `dev/tools/vendor_foundation.py`; don't edit them by hand. The Godot logo
icons (`Godot.svg`, `GodotFile.svg`, `GodotMonochrome.svg`) are deliberately excluded. Phoenix's
own icons go in a separate folder so updates never overwrite them. See `THIRD_PARTY_NOTICES.md`.
